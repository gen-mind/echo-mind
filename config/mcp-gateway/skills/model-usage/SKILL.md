# Model Usage & Cost Tracking

View LLM usage statistics, token consumption, and cost tracking via EchoMind's Langfuse integration. This is a documentation-only skill.

## Langfuse Dashboard

Access the Langfuse dashboard to view usage metrics:

```
https://langfuse.demo.echomind.ch
```

## Key Metrics

### Token Usage
- **Input tokens** — tokens sent to the LLM (prompts, context, RAG results)
- **Output tokens** — tokens generated by the LLM (responses)
- **Total tokens** — combined input + output per request

### Cost Tracking
- **Cost per session** — total cost of a conversation
- **Cost per user** — aggregated spending by user
- **Cost per model** — breakdown by model (GPT-4, Claude, local models)
- **Daily/weekly/monthly trends** — spending over time

### Performance Metrics
- **Latency** — response time per request
- **Throughput** — requests per minute/hour
- **Error rate** — failed LLM calls

## Dashboard Views

| View | Description |
|------|-------------|
| **Traces** | Individual request traces with full prompt/response |
| **Sessions** | Grouped by conversation session |
| **Users** | Usage aggregated by user |
| **Models** | Breakdown by LLM model |
| **Cost** | Cost analysis and trends |
| **Metrics** | Latency, throughput, error rates |

## Programmatic Access

Langfuse provides an API for programmatic access to usage data:

```bash
# Get traces (recent LLM calls)
curl -s -u "pk-...:sk-..." https://langfuse.demo.echomind.ch/api/public/traces?limit=10

# Get usage summary
curl -s -u "pk-...:sk-..." https://langfuse.demo.echomind.ch/api/public/metrics/daily
```

## Tips

- Use the **Sessions** view to see cost per conversation
- Filter by **model** to compare costs across providers
- Set up **alerts** in Langfuse for budget thresholds
- Use **tags** to categorize and filter traces (e.g., by assistant type)
